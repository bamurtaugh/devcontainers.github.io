Available Dev Container Features and Templates

This page contains all official and community-supported Dev Container Features and Dev Container Templates known at the time of crawling each registered collection. This list is continuously updated with the latest available information. See the Feature quick start repository and Template quick start repository to add your own!

Referencing a Feature can be done in the "features" section of a devcontainer.json. Templates listed here will be presented in the UX of supporting tools.

Please note that if you need to report a Feature or Template, you should do so through the registry hosting it.

To add your own collection to this list, please create a PR editing this yaml file.
